# Exercício 9: Tratamento de exceções

Projeto Java independente correspondente à questão 9 da lista de POO.

- Código-fonte: pasta `src`.
- Classe principal: `TesteQuestao09`.
- Requisito: JDK 8 ou superior.
- Dependências externas: nenhuma.

## Executar

No VS Code, abra esta pasta e execute o método `main` de `TesteQuestao09.java`.
No Eclipse, importe esta pasta como projeto existente.

Pelo terminal, dentro desta pasta:

```sh
mkdir bin
javac -encoding UTF-8 -d bin src/*.java
java -cp bin TesteQuestao09
```

Se `bin` já existir, pule o comando `mkdir bin`.
O separador decimal da saída depende da configuração regional do computador.
